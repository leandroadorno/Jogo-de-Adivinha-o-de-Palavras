# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I.

## Integrantes

- Nome do aluno 1
- Nome do aluno 2 (se houver)

## Como jogar

Digite uma letra e clique em Tentar (ou pressione Enter). O objetivo é descobrir a palavra antes de acabar as tentativas.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Palavra aleatória (10 palavras)
- Controle de tentativas
- Letras utilizadas, com bloqueio de letras repetidas
- Mensagens de vitória e derrota
- Reinício da partida
- Desafio extra: envio da letra com a tecla Enter
